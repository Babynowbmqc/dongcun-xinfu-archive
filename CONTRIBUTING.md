# Contributing / 参与修改

Thank you for helping polish the Dongcun Xinfu archive website.

## Recommended workflow

1. Fork the repository or create a new branch.
2. Keep each change focused and explain its intention.
3. Run `pnpm build` before opening a Pull Request.
4. Submit a Pull Request with screenshots when a visual change is involved.
5. Wait for review before merging into `main`.

## Useful contributions

- Mobile and responsive refinements
- Accessibility and keyboard-navigation improvements
- Chinese or English translation corrections
- Performance and loading improvements
- Visual polish that respects the existing photographs, textiles, typography, and archive structure

## Please preserve

- The official English name: **Dongcun Xinfu Shanzhai Chaoshan Opera Troupe**
- The original Are.na channel and block order
- The Chinese originals alongside English working translations
- The one-click Chinese–English switch
- The opening stage animation and `371.JPG` hero image
- The Are.na and Instagram archive links

Do not reorganize the archive into categories. Do not replace, relicense, or reuse troupe materials outside this website without permission.

## Pull Request notes

Describe what changed, why it helps, and which screen sizes you checked. Keep unrelated changes in separate Pull Requests so they are easier to review.
